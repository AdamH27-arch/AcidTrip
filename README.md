On the right hand side of the screen under "Releases" click on "Acid Trip V1.0". 
There you will find "AcidTripWindowsBuild.zip" for windows users and "MacOS.app.zip" for mac users, click the desired folder and download.

Unzip the folder and in the case of windows user you will find a file called "GameTwo.exe" within the inner AcidTripWindowsBuild folder. This is the game file. Click this to play.
For Mac users, click through Mac.app -> Contents -> MacOS -> Game Two file. This is the file used to play the game.
